# server-init

# Инициализация сервера

Если `curl` ещё не установлен: `sudo apt update && sudo apt install -y ca-certificates curl`.

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/zlatoivan/server-init/main/config/init_server.sh)"
```

# Инициализация макбука

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/zlatoivan/server-init/main/config/init_mac.sh)"
```
